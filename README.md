# CampusCompute — Intelligent Job Scheduling and Resource Management

A modular C command-line prototype for the Operating Systems Level 3 mini-project. It demonstrates CPU scheduling, a synchronized producer-consumer logger, POSIX shared-memory IPC with named semaphores, Banker's safety algorithm, child-process monitoring, and a process resource limit.

## Requirements

- Linux/Ubuntu or WSL Ubuntu
- GCC
- GNU Make
- POSIX threads and POSIX shared-memory/semaphore support

## Build

From this directory:

```bash
make clean
make
```

The executable is `./campuscompute`.

## Commands

```bash
./campuscompute help
./campuscompute schedule fcfs
./campuscompute schedule rr
./campuscompute schedule priority
./campuscompute schedule compare
./campuscompute schedule compare sample_jobs.txt
./campuscompute logger
./campuscompute ipc
./campuscompute banker safe
./campuscompute banker unsafe
./campuscompute worker normal
./campuscompute worker fail
./campuscompute limit
./campuscompute integrated
```

Scheduling commands use the same built-in sample dataset so that policies can be compared reproducibly. RR uses a time quantum of 2. For Priority Scheduling, a lower number means higher priority; ties are broken by earlier arrival time and then lower job ID. This prototype uses repeatable test jobs rather than an interactive job-entry interface.

`logger` writes generated events to `campuscompute.log`. `ipc` creates unique program-named shared-memory/semaphore objects and removes them on normal cleanup. `worker fail` deliberately exits the child with status 7 to demonstrate detection of a simulated failure. `limit` sets `RLIMIT_FSIZE` only in a child process and removes its temporary test file.

## Test

```bash
make test
./campuscompute logger
cat campuscompute.log
./campuscompute ipc
./campuscompute limit
./campuscompute not-a-command
```

The invalid command should return status 2 and display usage information.

## Cleanup

```bash
make clean
```

The IPC command performs its own shared-memory/semaphore cleanup. The logger joins its threads and closes the log file. Worker commands collect children with `waitpid()`. The resource-limit command removes its temporary file. `make clean` removes build outputs and local generated test files.

## Implementation map

- `src/main.c`: command-line interface and integrated demonstration
- `src/scheduling.c`: job data/input validation, FCFS, Round Robin, non-preemptive Priority, and scheduling metrics
- `sample_jobs.txt`: repeatable external example input for scheduling
- `src/logger.c`: bounded producer-consumer queue using POSIX threads, mutex and condition variables
- `src/ipc.c`: shared memory and named semaphore coordination between parent and child
- `src/banker.c`: `Need = Maximum - Allocation` and safety sequence detection
- `src/worker.c`: `fork()`, `waitpid()`, normal exit and simulated non-zero exit
- `src/resource_limit.c`: `setrlimit(RLIMIT_FSIZE, ...)` demonstration
